# Security and incident reports

This repository is a development reference for the private Simply360 integration
acceptance app. The selected milestone permits synthetic publisher-test-Team
data only. It does not authorize customer or production data.

Send security and incident reports to the escalation address published in the
app manifest: support@simply360.app. Include the app version and public
installation or event identifiers needed to locate the problem. Do not include
OAuth tokens, signing keys, passwords, or customer data in a public issue.

The [security review](docs/security-review.md) records the reviewed trust
boundaries and known limits. Deployed acceptance evidence is maintained
separately; passing source tests does not establish live-provider acceptance.

The [deprecation policy](docs/deprecation.md) covers compromised versions and
uninstall availability.
